# MNIST Digit Classifier - Manasvi

This project uses PyTorch to train a neural network to recognize handwritten digits from 0 to 9. It uses the MNIST dataset, which contains images of handwritten digits, to train the model to classify each image.

## Run

From the root of the repository:

```bash
uv run sandbox/manasvi/train.py
```

The MNIST dataset is downloaded automatically on the first run.
