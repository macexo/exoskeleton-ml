# Andrew's onboarding project

This project trains a small neural network from scratch with PyTorch to classify
the two interleaving classes in scikit-learn's synthetic moons dataset.

From the repository root, start JupyterLab:

```bash
uv run jupyter lab
```

Open `sandbox/andrew/train.ipynb`, choose the project's `.venv` Python kernel,
and select **Run > Run All**. After checking the results, clear all cell outputs
before saving the notebook.
